# Guide de démonstration

## Préparation

1. Retirer les anciennes versions dans `chrome://extensions`.
2. Charger le dossier 0.5.7 et actualiser Safinum.
3. Vérifier `Nolia 0.5.7` et le mode `Observation`.
4. Garder la preuve de validation linguistique disponible.

## Scénario

1. Montrer la page initiale en français.
2. Activer l’éwondo.
3. Parcourir solde, frais, bénéficiaire, récapitulatif et confirmation.
4. Montrer que montants, noms, téléphones et références ne changent pas.
5. Déclencher un message dynamique si possible.
6. Montrer qu’un message inédit reste en français avec un avertissement.
7. Restaurer le français sans recharger la page.

## Formulation pour le jury

> Nolia ne fait pas de traduction libre sur une opération financière. Elle
> reconnaît des messages et intentions contrôlés, conserve les valeurs, refuse
> les cas ambigus et restaure la source. Le traitement reste local dans Chrome.

Limites à annoncer : prototype Safinum, Chrome ordinateur, une seule langue,
couverture mesurée et aucune action sur la transaction.
